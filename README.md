# 💬 Connectly - Real-Time Chat App

A full-stack real-time chat application with secure authentication, instant messaging, and audio/video calling.

## 🚀 Features

- 🔐 User authentication using JWT
- 💬 Real-time messaging with Socket.IO
- 📞 Audio & Video calling using WebRTC
- 🖼️ Profile picture upload (Cloudinary)
- ⚡ Fast and responsive UI
- 🟢 Online/Offline user status

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Zustand

### Backend
- Node.js
- Express.js
- MongoDB
- Socket.IO

### Other Tools
- WebRTC (for calls)
- Cloudinary (image upload)
- Netlify (frontend deployment)
- Render (backend deployment)
